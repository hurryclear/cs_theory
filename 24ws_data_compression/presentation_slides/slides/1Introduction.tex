\subsection{Entropy Coding}
\begin{frame}[fragile]{Entropy Coding}
    \begin{itemize}
        \item The theoretical limit of compression is given by Shannon entropy, which measures the minimum average number of bits needed to encode a symbol from a data source.
        \item Lossless compression algorithms aim to approach this limit but cannot go below it.
        \item The entropy depends on the probability distribution of the symbols, with more skewed distributions being more compressible.
        \item Shannon Entropy \refer{1} $$\mathit{H(X) = -\sum_{i=1}^{n} p(x_i) \log_2 p(x_i)}$$ 
        \item Shannon's Source Coding Theorem \refer{1} $$\mathit{N \cdot H(X)}$$
    \end{itemize}
\end{frame}
